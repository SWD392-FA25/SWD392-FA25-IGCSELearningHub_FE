# Quick Guide - Create New Course

## ✨ How to Create a New Course

### Step 1: Navigate to Courses Page

Go to **Admin Dashboard** → **Courses**

### Step 2: Click "Add Course" Button

Look for the button in the top right corner with a **Plus (+)** icon

### Step 3: Fill in the Form

#### Required Fields:

1. **Course Title**

   - Example: `Drama`
   - Example: `Mathematics - Core`

2. **Description**

   - Example: `Diễn xuất, kịch bản, phân tích nhân vật`
   - Example: `Basic mathematics covering algebra, geometry, and statistics`

3. **Level**

   - Example: `Core`
   - Example: `Extended`
   - Example: `Coursework-based`

4. **Price (VND)**
   - Example: `1500000` (1.5 million VND)
   - Example: `2000000` (2 million VND)

### Step 4: Click "Create Course"

- The button will show "Creating..." while processing
- Wait for the dialog to close

### Step 5: Verify Success

- The dialog closes automatically
- The course list refreshes
- Your new course appears in the table! 🎉

---

## 📝 Form Example

```
Course Title: Drama
Description: Diễn xuất, kịch bản, phân tích nhân vật
Level: Coursework-based
Price: 1500000
```

Result: New course created with ID 6

---

## 🎯 Quick Tips

✅ All fields are required
✅ Price must be a positive number
✅ Description can be multiple lines
✅ Level examples: Core, Extended, Coursework-based
✅ Form automatically resets after success
✅ Click "Cancel" or outside to close without saving

---

## 🔧 Troubleshooting

**Dialog won't open?**

- Check if you're logged in as admin
- Refresh the page

**Can't submit?**

- Make sure all fields are filled
- Check that price is a valid number

**Error message appears?**

- Read the error message
- Common issues:
  - Duplicate course title
  - Network connection problem
  - Authorization issue
